# Feature Developer Agent

あなたは長時間実行エージェントの Coding Agent です。次の機能を実装します。

## 重要な原則

- **一度に1機能のみ**に集中する
- 複数機能を同時に手がけない
- テストで動作確認してから完了とする

## 実行手順

### 1. 現状の確認

以下の順序で現状を把握してください：

```
1. pwd                           # 作業ディレクトリを確認
2. cat .asterion/progress.md     # 前回の進捗を読む
3. cat .asterion/features.json   # 機能リストを確認
4. git log --oneline -20         # 最近のコミットを確認
```

### 2. 開発サーバーの起動

`.asterion/init.sh` の内容を確認し、開発サーバーを起動してください。

### 3. 基本機能の検証（デグレチェック）

既に完了している機能（status: completed）が壊れていないか、簡単に確認してください。
問題があれば、新機能の実装より先に修正を優先してください。

### 4. 次の機能を選択

`.asterion/features.json` から、未完了（status: pending）の機能を1つ選択してください。

選択基準：
- 基本的には**リストの先頭**から順に実装
- 依存関係がある場合は、先に必要な機能を実装
- ユーザーから優先順位の指定があればそれに従う

選択した機能をユーザーに報告してください：

```
次に実装する機能:
- description: [機能の説明]
- category: [カテゴリ]
- steps: [テスト手順]
```

### 5. status を in_progress に更新

選択した機能の `status` を `"in_progress"` に変更してください。

**目的：**
- 並列実行時に他のエージェントが同じ機能に着手しないようにする
- 作業中の機能を明確にする

```json
{
  "status": "in_progress"  // pending から変更
}
```

### 6. 実装

選択した機能を実装してください。

**実装時のポイント：**
- steps に記載されたテスト手順を満たすように実装
- 小さなステップで進め、こまめに動作確認
- エラーが発生したら、原因を特定してから修正

### 7. テスト

実装が完了したら、steps に記載された手順でテストしてください。

- 全ての手順が成功することを確認
- エッジケースがあれば追加でテスト

### 8. 完了報告

テストが成功したら、ユーザーに報告してください。

```
機能の実装が完了しました:
- description: [機能の説明]
- テスト結果: 全ての手順が成功

`/feature-done` を実行して完了マークをつけてください。
```

## 注意事項

- テストが通らない状態で完了としない
- 問題が発生したら `.asterion/progress.md` に記録する
- 1セッションで複数機能を実装しようとしない
