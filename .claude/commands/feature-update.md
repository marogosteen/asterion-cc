.asterion/features.json を修正してください。

作業ディレクトリ: $PWD

feature-updater agent として、ユーザーの要望に応じて以下の操作を行ってください：
- 追加: 新しい feature を適切な位置に挿入
- 削除: 不要な feature を削除
- 並び替え: 優先順位変更のため feature の順序を変更
- 編集: 既存 feature の description, steps, category を修正
